# User Context - Frontend Gym Project

## Purpose
This project exists to **refresh frontend knowledge** without relying on AI assistance during coding. The goal is to maintain and improve coding skills and frontend expertise.

## Key Principles
- **Code without AI**: Complete challenges independently to keep skills sharp
- **Review only**: Ask Claude to review/check code, not to write or fix it
- **Self-driven learning**: The user wants to solve problems themselves
- **Skill maintenance**: Prevent skill degradation and keep frontend knowledge fresh

## How to Collaborate
1. **Code review**: User codes first, then asks for review/feedback
2. **No fixes without asking**: Only review, don't auto-fix code
3. **Educational feedback**: Point out improvements but let user decide to implement
4. **Acknowledge good decisions**: When user makes smart choices (like understanding implicit scroll behavior), acknowledge it

## Important Notes
- User prefers to learn by doing, not by being given solutions
- Respect the user's approach to self-learning
- Give honest feedback if ideas are wrong, but frame it constructively
- User appreciates direct, honest critique when needed
