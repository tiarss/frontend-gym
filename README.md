## 📚 Levels

### ✅ [Level 1 - React Frontend Foundation](/docs/Back_to_the_Root_Level_1.md)

**Goal**: Memahami alur Request → State → Render menggunakan React + TypeScript tanpa bantuan library tambahan.

**Status**: Completed 🎉

**Key Topics**:
- Fetch API & async/await
- State management (useState)
- Effects (useEffect)
- Component composition
- Pagination
- Error handling & loading states

**Challenges**:
1. Hello PokeAPI - Basic fetch & display
2. Loading State - Handle async operations
3. Error State - Error handling with try/catch
4. Empty State - Handle empty data
5. Pokemon Card - Component & props
6. Pagination - Navigate between pages
7. Disable Navigation - Conditional UI
8. Scroll To Top - UX improvement
9. Cache Analysis - Caching strategy
10. Refactor - Code organization

**Tech Stack**: React 19 + Vite + TypeScript
